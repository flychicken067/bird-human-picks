图鉴笔记

身体几乎全白、头颈裸露黑色，喙厚而下弯的鹮。

  • 身体白色，腰有深色饰羽
  • 头和颈是秃的，黑色
  • 喙厚而弯，黑色
  • 飞行时翼后缘有黑边

雌雄相似；雏鸟灰白，喙较短，颈上有些羽毛。

古埃及人奉它为智慧之神托特的象征，常把它做成木乃伊。
