图鉴笔记

长直的深色嘴，觅食时像缝纫机一样一下一下往下探。

  • 喙长而直，深色
  • 腿深色
  • 繁殖羽上体棕色，下体红色
  • 尾有黑白相间的横斑

它的繁殖区和冬季栖地，到现在都还不太为人所知。
