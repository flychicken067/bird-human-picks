图鉴笔记

黑帽子，天蓝色的翅和长尾，成群在公园里穿梭。

  • 头顶、颈侧、后颈饱满的黑色
  • 飞羽、尾羽和下背天蓝色
  • 尾羽长，几乎和身体等长，端白
  • 肩和上背石板灰，下体污白

雌雄同形同色；幼鸟头顶黑色羽毛端部污白，尾羽较短。

有的地方专门保护繁殖灰喜鹊来保护松林；它也是安徽的省鸟。
