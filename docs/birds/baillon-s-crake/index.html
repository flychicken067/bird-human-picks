图鉴笔记

小巧的秧鸡，脸和下体蓝灰，繁殖季躲在莎草沼泽里很隐秘。

  • 嘴短直，黄色或绿色，没有红色基部
  • 脸和下体蓝灰色
  • 肋部和尾下有黑白横纹
  • 上体棕褐，带些白斑点

幼鸟像成鸟，但下体条纹更多。

繁殖季非常隐秘，多数时候是听到叫声才知道它在。
