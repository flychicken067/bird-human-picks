图鉴笔记

站着时，长翅尖一直伸到尾巴后面。

  • 站立时翅尖超出尾端
  • 成鸟腰部有黑斑
  • 成鸟头胸浅褐，带深色纵纹
  • 成鸟腿黑，嘴短直细暗

迁徙和越冬时，常到安第斯山的湖岸和稀疏草地，最高达海拔4700米。
