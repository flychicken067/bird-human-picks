图鉴笔记

红棕背、蓝灰嘴，雌鸟比雄鸟更抢眼。

  • 背部红棕色
  • 嘴和腿蓝灰色
  • 雌鸟喉和胸中央黑色
  • 飞起时翼肩有浅黄斑

雌鸟更大、颜色更鲜艳，喉和胸中央黑色。

雌鸟主动求偶、筑巢，产卵后由雄鸟孵蛋和带小鸟。
