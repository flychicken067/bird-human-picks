图鉴笔记

像赤腹鹰的暗色版：上体更暗，喉纹更宽。

  • 成年雄鸟上体深蓝灰色
  • 成年雄鸟下体白带红棕条纹
  • 尾上有3到4条同样大的暗色横纹
  • 短而宽的翅，长尾巴

雌鸟比雄鸟大，上体更棕；幼鸟上体深棕，下体白带棕色条纹。

飞行有固定节奏：拍翅、拍翅、再滑翔。
