图鉴笔记

雄鸟黑羽泛蓝，尾羽向两侧卷成琴形。

  • 雄鸟颈背黑色泛深蓝
  • 雄鸟翼线和尾下覆羽白色
  • 雄鸟眼上有红色裸皮
  • 雄鸟外侧尾羽长，向外卷曲

雄鸟以黑色为主；雌鸟灰褐色，羽色更隐蔽。

春天黎明，雄鸟聚到展示场，展开琴形尾巴比试求偶。
