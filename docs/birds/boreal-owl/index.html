图鉴笔记

成鸟白眉配黄眼，常被说像有点吃惊。

  • 成鸟白色面盘有深色边框
  • 成鸟眼睛黄色
  • 成鸟褐色背翼有显眼白斑
  • 成鸟嘴淡黄色

雌雄外形相似，雌鸟更大。

它常借用啄木鸟留下的树洞做巢，也会住进巢箱。
