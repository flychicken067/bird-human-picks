图鉴笔记

小个子棕褐色莺，爱躲藏，靠响亮的歌声暴露行踪。

  • 细浅灰眉纹，眼睛黑而醒目
  • 上体深栗色或红褐色
  • 喉和胸浅灰褐色
  • 尾比许多莺更长更宽

雌雄羽色相近，雄鸟体重和翼长都明显更大。

尾羽是10根，不同于雀形目常见的12根。
