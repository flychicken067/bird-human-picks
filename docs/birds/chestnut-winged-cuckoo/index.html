图鉴笔记

黑色长羽冠，配一双栗色翅膀。

  • 头黑，羽冠长而有光泽
  • 翅膀栗色
  • 后颈有窄白色半领圈
  • 尾长，中央羽比外侧长

幼鸟颜色较暗，翅羽带鳞状花纹。

通常独来独往，有时也会加入别种鸟的觅食队伍。
