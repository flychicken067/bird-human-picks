图鉴笔记

飞起来白翅白尾很显眼；冬羽头颈胸杂有棕黄纵纹。

  • 翼白，冬羽身具褐色纵纹
  • 繁殖羽头颈胸栗红，背紫黑
  • 冬羽头颈胸栗色偏浅，杂棕黄纵纹
  • 喙黄色，尖端黑；虹膜金黄

雌雄同色，雌鸟体形略小；冬羽和亚成鸟头颈胸偏浅，没有长冠羽。

1997年有一只迷路的池鹭飞到阿拉斯加的圣保罗岛，是北美首次记录。
