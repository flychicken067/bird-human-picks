图鉴笔记

黑带围出白喉像项圈，红腿红嘴，两胁黑白条纹。

  • 黑带过眼围成项圈，圈住白喉
  • 两胁有黑白横纹
  • 嘴珊瑚红，腿红色
  • 背浅褐，胸灰，腹皮黄

雌雄相似，雌鸟稍小且没有距。

名字chukar来自它吵闹的叫声「chuck-chuck-chukar-chukar」。
