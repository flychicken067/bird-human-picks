图鉴笔记

成鸟蓝头红胸、嘴橙红，羽色鲜艳的吸蜜鹦鹉。

  • 头部蓝色，向颈部渐变褐色
  • 嘴橙红色
  • 颈上有或宽或窄的黄色领环
  • 成鸟胸部红色，上体绿色

雌雄外形相似，虹膜颜色差异受健康影响，不宜单凭它辨性；幼鸟较暗、较小。

聪敏机灵，能学会各种把戏，语言能力也相当不错。
