图鉴笔记

像燕子一样飞着捉虫的涉禽，尾长而分叉。

  • 翅长而尖，腿短
  • 尾长而分叉
  • 头和背褐色，腹白
  • 翼下栗色，看着发暗

属名Glareola来自拉丁语「砾石」，指这类鸟典型的营巢地。
