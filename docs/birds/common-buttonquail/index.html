图鉴笔记

宁可在地上跑，也不轻易起飞的小鸟。

  • 上体沙褐色，带纵纹
  • 下体浅黄，胁部有黑斑
  • 脸上没有花纹
  • 飞起时灰翅上有一道白纹

雌雄相似，幼鸟下体的斑点更多。

雌鸟主动求偶、筑巢，孵蛋和带小鸟则交给雄鸟。
