图鉴笔记

浅灰色的鹤，头颈黑，眼后白纹伸到颈背，头顶一点红。

  • 头颈灰黑或黑，眼后白纹到颈背
  • 头顶有一小片裸露的红皮
  • 全身以灰色为主
  • 站立时尾上垂着松散羽簇

雌雄羽色相同，雄鸟通常体型较大。亚成鸟大致黄褐，头顶深褐，颈部没有黑白条纹。

和沙丘鹤一样，会往身上涂泥巴或腐烂植物，像是为了融进巢区环境。
