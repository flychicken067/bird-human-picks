图鉴笔记

身体灰色修长，尾很长，飞起来像雀鹰

  • 成年雄鸟板岩灰色
  • 成年雄鸟灰喉至胸，与下体横斑分明
  • 虹膜、眼圈、嘴基和脚黄色
  • 繁殖季常栖开阔处，翅下垂尾上翘

雌鸟多为灰色，偶有红褐色型，幼鸟中红褐色型更常见；幼鸟最明显的是白色颈背斑和白色羽缘

雏鸟孵出后会用背把宿主的蛋推出巢外，独占养父母的喂食
