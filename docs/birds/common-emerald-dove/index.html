图鉴笔记

背翅鲜绿的矮胖鸠，嘴鲜红，飞时下背现黑白宽条。

  • 背部和翅膀鲜绿色
  • 嘴喙鲜红色
  • 飞行时下背部露出宽阔黑白条
  • 头和腹部略带酒红的棕色

雄鸟肩缘有白斑、头顶灰色，雌鸟没有，体色偏棕褐；亚成鸟像雌鸟，身体和翅膀有褐色贝状纹。

通常在五米以下的树上用小树枝筑巢，每巢多产两枚奶油色的蛋。
