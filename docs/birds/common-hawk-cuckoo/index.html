图鉴笔记

灰背黄眼圈，飞行时一阵拍翅、一阵滑翔。

  • 眼圈黄色
  • 上体灰色
  • 下体偏白，带褐色横纹
  • 尾部有宽横纹

雌雄羽色相似，雄鸟往往更大；亚成鸟胸带纵纹，腹部有大块褐色V形斑。

吃毛毛虫时，会先压挤、蹭树枝去掉肠道；吞下的毛在胃里分离，再吐成团。
