图鉴笔记

长直嘴的棕斑小涉禽，被惊起时之字形飞走。

  • 嘴长直，深色
  • 身体棕色斑驳，上有稻草黄纹
  • 过眼深色纹，上下有浅色纹
  • 腿短灰绿，翅尖形

雄鸟求偶时高飞后浅俯冲，振动尾羽发出「嗡嗡」声，有人比作羊叫，多种语言称它「飞羊」或「天羊」。
