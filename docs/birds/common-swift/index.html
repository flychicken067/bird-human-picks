图鉴笔记

全身黑褐，长翅后掠像新月，除了筑巢几乎都在空中。

  • 黑褐，颏有白或浅灰小斑，远看不见
  • 翅又长又后掠，像新月或回力镖
  • 尾短，呈叉形
  • 窄镰刀形翅，比身体还长

有的个体能连续十个月不落地，吃喝都在空中，也常在空中睡觉和交配。
