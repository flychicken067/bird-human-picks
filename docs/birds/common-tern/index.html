图鉴笔记

繁殖期黑帽、橙红腿，站着时尾巴不超过翼尖。

  • 繁殖期头顶黑帽
  • 嘴细尖，红色黑尖（部分亚种全黑）
  • 繁殖期腿橙红色
  • 站着时长尾只到翼尖，不超出

雌雄没有明显差别；幼鸟头顶和后颈褐色，额头姜黄色。

雄鸟把鱼送给雌鸟，是一种求爱的表示。
