图鉴笔记

黑白相间的大型鱼狗，头顶有蓬乱的黑白横纹羽冠。

  • 蓬乱的黑白横纹羽冠
  • 喙大而尖，黑色，尖端黄白
  • 上体黑白细横纹，胁有灰白相间横纹
  • 白领圈，腹白，胸带有黑点

雌雄体型一样；雌鸟翼下覆羽粉肉桂色，雄鸟没有，但胸带上有橙红色羽毛。

很少悬停后俯冲，多半从高处的栖枝直接头朝下扎进水里捕鱼。
