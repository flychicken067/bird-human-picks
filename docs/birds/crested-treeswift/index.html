图鉴笔记

顶着羽冠，长翅后掠，尾巴深深分叉。

  • 头上有羽冠，尾长而深叉
  • 上体鸽灰色，下体白色
  • 长翅向后掠，上面深灰色

雄鸟脸颊橙色，雌鸟脸颊灰色；两者眼下都有细白纹。

巢很小，蛋近一半高出巢沿，孵卵时由亲鸟胸腹绒羽覆盖。
