图鉴笔记

长喙向下弯，繁殖期下身砖红的小型滨鹬。

  • 喙黑色，长而向下弯
  • 腰有大白斑，飞时翼上有白带
  • 繁殖期上身暗灰带斑，下身砖红
  • 冬羽上灰下白，白眉斑明显

繁殖期雄鸟的锈红更浓；幼鸟背灰褐、腹白，胸带桃色。

繁殖成功与旅鼠数量有关：旅鼠多的年份，天敌改捕旅鼠。
