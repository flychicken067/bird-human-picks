图鉴笔记

后脑有蓬乱卷羽、银白身体灰腿，鹈鹕里体型最大。

  • 嘴巨大，下挂大喉囊
  • 后脑到颈背有蓬乱的卷羽
  • 腿深灰色
  • 翼宽浅灰白，初级飞羽尖黑

雄鸟比雌鸟大；幼鸟整体更灰更暗，冠羽不如成鸟明显。

嘴通常长37到45厘米，是嘴第二长的鸟，仅次于澳洲鹈鹕。
