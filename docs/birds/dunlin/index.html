图鉴笔记

繁殖期肚子黑黑的小涉禽，嘴黑而微微下弯

  • 繁殖羽有黑色的腹部
  • 冬羽上体灰褐，下体白
  • 腿黑，嘴黑且微微下弯
  • 飞行时有一道窄白翼斑

幼鸟上体棕色，背上有两道不明显的白色V形纹；雌鸟的嘴比雄鸟长

嘴尖有一层软组织，布满血液和神经末梢，像灵敏的探测器
