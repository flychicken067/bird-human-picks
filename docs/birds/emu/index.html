图鉴笔记

蓬松褐羽、长脖子长腿，不会飞却善于奔跑。

  • 体羽灰褐，显得蓬松
  • 颈长，稀疏羽下透出浅蓝皮肤
  • 腿长，没有羽毛
  • 每只脚有三根趾

雌雄外观相似，雌鸟通常稍大，腰部明显更宽。

它会吞下小石头，帮助消化食物。
