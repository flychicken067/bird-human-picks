图鉴笔记

黑白分明，长直嘴橙红，眼睛也是红的，爱吵闹的涉禽。

  • 黑白相间的羽毛
  • 喙长而笔直，橙红色
  • 眼睛红色，腿暗粉红且较短
  • 飞行时翼、尾有白斑，背黑腹白

雌雄羽色相似，雌鸟喙稍长；幼鸟偏棕，有白色颈圈，喙较暗。

名字带「蛎」，但牡蛎不是主食；不过很少有别的涉禽能像它一样打开牡蛎。
