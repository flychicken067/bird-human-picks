图鉴笔记

头顶撒着白点的小鸮，脑后还有半圈白领。

  • 头顶灰色，布满白点
  • 头小而短，没有耳羽簇
  • 后颈有半圈白领
  • 尾通常较暗，有五道淡白横纹

雌鸟通常比雄鸟更大、更重。

秋天会囤下许多小兽和小鸟，留到冬天补充食物。
