图鉴笔记

小个子猫头鹰，羽色像树皮，白天伪装成一截断枝。

  • 灰褐到棕红，整体像树皮
  • 耳羽很短，平时几乎看不见
  • 指名亚种成鸟虹膜黄，嘴灰或蓝黑
  • 肩上有一排浅白斑点

雌鸟比雄鸟重约15到25克；亚成鸟和成鸟几乎一样，只是耳羽更短、背上白斑不明显。

白天被人靠近，会伸直身体、竖起耳羽，眼睛眯成竖缝。
