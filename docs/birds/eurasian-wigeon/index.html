图鉴笔记

雄鸟栗红色的头配一块乳黄额顶，十分醒目。

  • 雄鸟头颈棕红，额顶乳黄
  • 雄鸟上体灰白，密布暗褐细波纹
  • 雄鸟尾上尾下覆羽黑色
  • 雄鸟翼镜翠绿镶黑，次级覆羽白

雌鸟通体棕褐，腹部纯白；雄鸟非繁殖期的蚀羽更像雌鸟。

吃植物为主，越冬鸟的胃里除植物外只有帮助磨碎食物的石块。
