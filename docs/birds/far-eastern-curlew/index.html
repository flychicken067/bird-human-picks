图鉴笔记

最大的杓鹬，喙极长而下弯，全身以棕色为主。

  • 喙极长，向下弯曲
  • 通体主要是棕色
  • 翼下覆羽单一棕色、无图案
  • 腰和背下部棕色，不是白色

雌鸟平均比雄鸟重约100克。

种加词madagascariensis意为「马达加斯加的」，实为误记，该种从未在马达加斯加有过记录。
