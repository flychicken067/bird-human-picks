图鉴笔记

胸前两道黑带，尾巴左右摆的林中鹡鸰。

  • 胸前两道黑带，上带如领结
  • 白眉纹，眼部有深色条纹
  • 翅黑，有两道宽大的白色翼斑
  • 背和头顶橄榄棕色

雌雄外观相似；幼鸟下体偏黄。

它是唯一在树上筑巢的鹡鸰。
