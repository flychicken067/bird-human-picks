图鉴笔记

繁殖期红褐色身体配亮绿翅膀，嘴形像镰刀。

  • 繁殖期身体红褐，翅膀闪亮瓶绿
  • 嘴褐色，形状像镰刀
  • 脸部皮肤暗色，上下有蓝色边
  • 腿红褐色；飞行时颈伸直

非繁殖期成鸟和幼鸟身体较暗淡，头颈深褐，有细白纹。

在欧、亚、非、澳洲和美洲都有繁殖，是分布最广的鹮类。
