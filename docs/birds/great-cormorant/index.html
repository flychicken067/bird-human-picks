图鉴笔记

通体偏黑闪光的大水鸟，爱停在岩石或树枝上晾翅膀。

  • 全身偏黑，带闪光
  • 嘴厚重，下嘴基黄色裸皮
  • 脸颊和喉白色
  • 繁殖期头颈白丝羽，胁有白斑

雄鸟通常比雌鸟大；幼鸟深褐色，下体污白。

渔民给鸬鹚套上颈圈，只让它吞小鱼；捕到大鱼就换小鱼奖励。
