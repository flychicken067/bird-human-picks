图鉴笔记

全身雪白的大型鹭，黄嘴黑腿，飞行时缩着脖子。

  • 全身白色
  • 非繁殖期嘴黄，腿脚黑
  • 嘴裂长，伸到眼后很远
  • 繁殖期背有饰羽，嘴可变黑

雌雄外形一样；幼鸟像非繁殖期的成鸟。

鹭和麻鳽飞行时缩着脖子，鹳、鹤、鹮、琵鹭则把脖子伸直。
