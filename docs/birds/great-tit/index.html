图鉴笔记

黑头白脸颊，黄胸正中一道黑线的山雀。

  • 黑头黑颈，脸颊白色
  • 胸亮黄，正中一道黑纵带
  • 背橄榄绿，翼蓝灰带白翼带
  • 尾蓝灰，外侧尖端白

雌鸟整体色更暗，胸兜黑色较淡，腹中线也较淡较窄、有时断开；幼鸟似雌鸟，后颈和颈部暗橄榄褐。

英国的大山雀学会了啄破门口奶瓶的锡箔盖偷喝奶油，1921年首次记录，随后迅速传开。
