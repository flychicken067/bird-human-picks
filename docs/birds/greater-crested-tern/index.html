图鉴笔记

黄嘴灰背白肚皮的大型燕鸥，头顶一撮蓬乱的黑冠。

  • 喙长，黄色
  • 繁殖期黑羽冠光亮，后部蓬乱
  • 额头和下体白，背和内侧翅膀暗灰
  • 冬羽头顶变白，后部黑冠斑杂

雌雄成鸟一模一样；幼鸟头部像冬羽成鸟，上体有明显的灰、棕、白斑纹。

会跟着渔船捡被丢弃的渔获；在南非，还有在建筑物屋顶上繁殖的。
