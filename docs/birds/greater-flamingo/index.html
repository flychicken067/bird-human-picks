图鉴笔记

羽毛以粉白为主，翼覆羽红、飞羽黑，是体型最大的火烈鸟。

  • 羽毛主要是粉红白色
  • 翼覆羽红色，主次飞羽黑色
  • 嘴粉红，尖端黑
  • 腿全是粉红色

雏鸟披灰色绒毛；亚成鸟颜色更浅，腿是深色。

繁殖季会往羽毛上多抹尾脂腺分泌物，让颜色更鲜艳。
