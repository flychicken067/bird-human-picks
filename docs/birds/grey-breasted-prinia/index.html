图鉴笔记

繁殖期烟灰胸带配白喉，尾常翘起，在灌丛枝间抖着尾巴蹿动。

  • 繁殖期有烟灰色胸带，对比白喉
  • 喙全黑，腿粉红色
  • 眼圈橙色
  • 尾长，灰色，羽端白色

多数种群雌雄相似；非繁殖期成鸟常没有胸带，幼鸟像非繁殖成鸟，但背上更偏棕。

吃花蜜时额头有时会沾上花粉，变成橙黄色，容易认错。
