图鉴笔记

身子圆滚滚，白肚皮上常有栗色马蹄斑。

  • 背部褐色
  • 胸和两胁灰色
  • 白腹常带栗色马蹄斑

雌鸟羽色通常稍暗，腹部深斑较小；幼鸟多黄褐色，没有醒目的脸部和下体斑纹。

亲鸟会带着雏鸟到谷物田边，让它们寻找昆虫。
