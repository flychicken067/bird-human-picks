图鉴笔记

尾巴又长又宽，颜色深而偏冷。

  • 尾巴长而宽，颜色深
  • 繁殖雄鸟头顶、脸近黑色
  • 繁殖雄鸟胸侧深、有斑驳
  • 繁殖雄鸟嘴近黑色

繁殖期雌鸟颜色较浅、纵纹较少，嘴带浅粉色。

到了非繁殖期，雌雄上体都会有纵纹，脸侧和胸部也有斑驳。
