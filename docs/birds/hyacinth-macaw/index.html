图鉴笔记

一身紫蓝色，眼周和嘴基的黄色格外醒目。

  • 成鸟羽毛以紫蓝或钴蓝为主
  • 眼周和嘴基裸皮黄色
  • 喙灰黑色
  • 尾巴长而尖

雌雄相似；幼鸟裸皮颜色较淡，尾巴较短。

圈养个体会用木片或叶子固定坚果，防止啃咬时滑动。
