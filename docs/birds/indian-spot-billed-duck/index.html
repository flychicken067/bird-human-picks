图鉴笔记

灰色为主的鸭，头颈偏浅，嘴黑尖黄，体侧有白色三级飞羽条。

  • 嘴黑，尖端黄
  • 三级飞羽白，成一道白条
  • 头色浅，顶和眼线深
  • 喉颊皮黄，脚珊瑚红

雌鸟比雄鸟黯淡些；幼鸟更褐更暗。

受惊时能几乎垂直地从水面起飞。
