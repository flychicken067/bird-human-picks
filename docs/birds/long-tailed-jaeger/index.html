图鉴笔记

灰背黑帽、尾巴特别长，成鸟一眼就能认出来。

  • 背部灰色
  • 头顶黑帽
  • 尾很长，夏季有长尾羽
  • 初级飞羽深色，无白色闪斑

成鸟好认，幼鸟麻烦得多，羽色变化很大。

属名在拉丁语里是「粪的」：被追赶的鸟吐出的食物，曾被当成粪便。
