图鉴笔记

白身黑翅黑尾，脸上一圈黑色「面具」的大型鲣鸟。

  • 全身白，翅和尾黑
  • 脸喉裸皮黑或蓝黑，像面具
  • 长而尖的偏黄色喙
  • 腿黄橙色或橄榄色

雌雄羽色相似，雌鸟平均略重略大；幼鸟头背灰褐斑驳，颈有白领圈。

第二只出生的雏鸟通常无法生存，会被较大的兄弟姐妹杀死。
