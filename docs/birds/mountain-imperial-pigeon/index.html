图鉴笔记

栗褐色背，头颈和下体酒红灰，喉白，分布区里最大的鸠鸽。

  • 头颈和下体酒红灰色
  • 喉白，反差明显
  • 上体和翅栗褐色
  • 尾近黑，有一道灰横线

求偶时从栖枝垂直飞起6到8米，再张开翅尾滑降。
