图鉴笔记

雄鸟脖子是金属蓝色，眼周红色裸皮，尾羽灰白带黑、褐斑纹。

  • 颈部金属蓝色
  • 眼周裸露红色皮肤
  • 雄鸟尾羽长，灰白带黑、褐横斑
  • 头灰褐，嘴黄色，肩羽白

雌鸟体羽褐色，喉白，尾羽带白色尖端。

它是印度米佐拉姆邦和曼尼普尔邦的邦鸟，英文名纪念休姆夫人。
