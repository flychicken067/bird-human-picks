图鉴笔记

体型很大的鸥，夏天戴黑头罩，同样大的鸥里没有别的黑头。

  • 夏羽头戴黑色头罩
  • 背和翅灰色，翅尖有明显白斑
  • 腿黄色，嘴橙黄、尖端红
  • 其他羽色有贯眼深色眼罩

幼鸟上体很快变灰，要四年才成熟。

体长55到72厘米，是全世界第三大的鸥，仅次于大黑背鸥和北极鸥。
