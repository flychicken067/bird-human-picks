图鉴笔记

黑白分明的高脚水鸟，细长的嘴向上翘。

  • 嘴细长，向上翘起
  • 头顶黑帽，延伸到后颈
  • 身体白，翅和背有黑斑块
  • 腿蓝色，很长

雌雄外观相似，雄鸟喙更长更直，雌鸟喙更短更弯；幼鸟灰色和赭色更多。

觅食时把喙在水里左右扫动，这是反嘴鹬类独有的方式。
