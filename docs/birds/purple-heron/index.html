图鉴笔记

比苍鹭稍小、更纤细、羽色更暗红棕的鹭，爱躲在芦苇丛里。

  • 额和头顶黑，颈背黑纹通到细羽冠
  • 头颈两侧黄褐，带深色条纹
  • 胸棕色，腹部和尾下覆羽黑色
  • 喙棕黄色，又长又直

趾很长，能在浮动的植被上行走，有时还走过灌木，不去抓树枝。
