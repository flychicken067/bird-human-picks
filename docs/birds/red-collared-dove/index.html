图鉴笔记

雄鸟身体红褐、头颈青灰，颈后有黑色颈环的小斑鸠。

  • 雄鸟颈青灰色，颈后有黑色颈环
  • 雄鸟翅、胸腹、肩背红褐色
  • 体长约23厘米，在鸠鸽里偏小

雌鸟全身灰褐，比雄鸟略小，腿深褐色。

种名来自印度南部的城镇特兰奎巴，那也是它的模式产地。
