图鉴笔记

雄鸭顶着圆圆的橙色头，红嘴黑胸，特征明显。

  • 雄鸭头圆，橙色
  • 雄鸭喙红色
  • 雄鸭胸黑，两胁白
  • 雄鸭背棕色，尾黑色

雌鸭淡棕色，背和头顶较深，脸偏白；换羽期雄鸭像雌鸭，但喙是红色。

觅食时比多数潜鸭更爱倒栽葱，把身体倒立下去。
