图鉴笔记

喙尖交叉，能撬开针叶树球果的鳞片取出种子。

  • 喙尖交叉
  • 雄鸟多为红色或橙色
  • 雌鸟多为绿色或黄色
  • 翅膀全棕黑色，没有白翼斑

雄鸟多为红或橙色，雌鸟绿或黄色；幼鸟灰绿带纵纹。

传说耶稣被钉十字架时，它用嘴拔钉子，嘴才变成了交叉的样子。
