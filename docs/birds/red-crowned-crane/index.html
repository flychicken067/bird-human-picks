图鉴笔记

成鸟体羽大多洁白，次级飞羽黑，头顶裸皮鲜红。

  • 头顶裸露皮肤鲜红，繁殖季更亮
  • 成鸟整体洁白，次级飞羽黑
  • 站立时的黑「尾」其实是次级飞羽
  • 嘴橄榄绿至绿角质色，腿灰黑

幼鸟体羽棕黄；亚成体羽色黯淡，2岁后头顶红色裸区越发鲜艳。

传说「鹤顶红」剧毒是谣传，鹤血无毒，古人说的其实是砒霜。
