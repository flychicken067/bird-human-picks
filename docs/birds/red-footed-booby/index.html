图鉴笔记

脚红色、羽色有白色和棕色等多种色型的海鸟。

  • 脚红色，四趾朝前，趾间蹼发达
  • 白色型大多白色，飞羽黑色
  • 棕色型整体棕色；有的腹、腰、尾白
  • 喙粗壮，圆锥形，喙缘锯齿状

两性差别不大；幼鸟灰棕色，脚粉红色。

亲鸟不叼鱼喂雏，而是把胃里的食糜吐出来喂。
