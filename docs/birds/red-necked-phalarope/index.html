图鉴笔记

常在水面快速转圈觅食的小型涉禽，繁殖期雌鸟比雄鸟艳

  • 喙笔直细长
  • 繁殖雌鸟颈和上胸栗色
  • 翅上一条白色条纹
  • 冬季灰白，仍有黑眼斑

繁殖期雄鸟是雌鸟的暗淡版；幼鸟上体灰褐，下体黄褐

雌鸟追求并争抢雄鸟，孵蛋和带雏全由雄鸟负责
