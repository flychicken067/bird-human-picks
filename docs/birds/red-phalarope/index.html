图鉴笔记

觅食时常在水上快速转圈，搅出小漩涡。

  • 冬羽上灰下白，眼斑黑
  • 冬季嘴黑色
  • 繁殖期雌鸟腹红、颊白
  • 繁殖期雌鸟嘴黄、尖黑

雌鸟比雄鸟大、颜色更鲜艳；幼鸟背浅灰和棕色，腹黄褐，眼部有深斑。

雌鸟产卵后就南迁，留下雄鸟孵蛋、带幼鸟。
