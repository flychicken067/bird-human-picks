图鉴笔记

几乎全白，红嘴，深色眼纹，拖着红色长尾羽

  • 喙鲜红色，鼻孔周围黑
  • 两根橙红色长尾羽
  • 深褐色逗号状眼纹
  • 羽毛几乎全白，常带粉色

雌雄羽毛相似；幼鸟头背有黑色横斑和鳞纹，喙黑灰色
