图鉴笔记

黑色高冠，眼下后方一块红斑，尾下也是红的。

  • 头顶黑色，有直立长羽冠
  • 眼下后方红斑，颊部白色
  • 胸两侧各有一道黑带
  • 外侧尾羽白端，尾下覆羽红

雌鸟与雄鸟相似，黑色部分换成黑褐色；亚成鸟没有红斑，尾下覆羽棕色。

吃的水果里有黄花夹竹桃的果实，这种果实对哺乳动物有毒。
