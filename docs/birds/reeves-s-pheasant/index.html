图鉴笔记

雄鸟拖着银白色的超长尾羽，头部白、黑、白相间。

  • 头白，黑带过眼并绕过脑后
  • 眼周裸皮鲜红
  • 胸、肩、背金黄，黑色鱼鳞斑
  • 中央尾羽极长，银白带横纹

雌鸟朴素得多，尾羽虽长但远不及雄鸟；头顶枕部黑褐，眼后有大块黑斑。

2008年版吉尼斯世界纪录提到它有鸟类中最长的天然尾羽，雄鸟尾巴每年约长出30厘米。
