图鉴笔记

繁殖期，多数雄鸟会竖起华丽的大羽领。

  • 繁殖期多数雄鸟有羽冠羽领
  • 繁殖期典型雄鸟背灰褐有鳞纹
  • 飞时可见细淡白翼带
  • 尾部两侧各有白色椭圆斑

雄鸟通常大得多，繁殖时披羽冠和羽领；幼鸟下体明显泛黄褐色。

觅食时常把背羽竖起来，背上像冒出一个松松的尖。
