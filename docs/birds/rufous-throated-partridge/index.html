图鉴笔记

喉和颈侧橙栗带黑点，胸肋蓝灰，脚粉红或深红的山鹧鸪。

  • 喉和颈侧橙栗色，带黑点
  • 胸和肋蓝灰色
  • 有白眉纹和髭纹弧线
  • 嘴暗褐近黑，脚粉红或深红

雌鸟和雄鸟相似；幼鸟下体更暗淡，头顶和肋部有褐黑细纹。

一群鸟夜里挤在树上栖息，像鹛类一样抱团。
