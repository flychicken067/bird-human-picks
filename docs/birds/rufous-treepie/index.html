图鉴笔记

黑头、肉桂色身体，拖着蓝灰长尾，叫声响亮。

  • 头黑色，身体肉桂色
  • 长尾蓝灰色，尾端黑色
  • 翅上有白斑，初级飞羽黑
  • 嘴粗壮、先端带钩，黑色

雌雄相似。

有个当地名字「taka chor」，意思是偷硬币的贼。
