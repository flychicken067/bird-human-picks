图鉴笔记

成鸟翅上黑、白、灰三色分明，白尾微叉的小鸥。

  • 成鸟灰背，初级飞羽外黑内白
  • 嘴黑，尖端黄
  • 成鸟白尾，略呈叉形
  • 繁殖期头罩深灰，下缘一道窄黑领

幼鸟翼面也是三色，但灰色换成褐色，尾有黑色端带；约两年才换成成鸟羽。

每年迁徙多达3.2万到3.9万公里，是所有鸥类里最长的迁徙。
