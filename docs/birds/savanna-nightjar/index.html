图鉴笔记

灰褐斑驳的夜鹰，雄鸟外侧尾羽几近全白。

  • 雄鸟最外侧两枚尾羽近全白
  • 全身灰褐，杂有细白点和虫蠹斑
  • 雄鸟喉部两侧各有椭圆白斑
  • 喙红褐色，尖端黑色

雄鸟喉部和外侧尾羽有白斑，雌鸟喉斑暗淡、尾羽全褐；幼鸟像雌鸟。

叫声可达90分贝以上，能传800多米；在中国台湾市区已让居民困扰。
