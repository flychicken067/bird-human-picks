图鉴笔记

长嘴在泥里快速探来探去，像踩着缝纫机。

  • 嘴长，体形敦实
  • 尾羽黑白横斑相间
  • 腿淡黄色
  • 冬羽大体灰色

它的英文名里虽有「短嘴」，嘴却并不短。
