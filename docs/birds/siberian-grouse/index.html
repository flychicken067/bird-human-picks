图鉴笔记

圆墩墩的林栖松鸡，雄鸟黑喉围白边，眼上有红皮。

  • 雄鸟羽色煤灰褐，颈有领羽
  • 雄鸟黑色喉斑镶白边
  • 雄鸟每只眼上有红色裸皮
  • 腹胁满布白斑，尾端有白色带

雌鸟偏浅褐色，没有雄鸟那样清晰的脸部标记。

似乎不太怕人，被靠近时常原地不动或继续活动。
