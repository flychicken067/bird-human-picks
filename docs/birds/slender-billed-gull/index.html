图鉴笔记

白头白胸，嘴细长而暗红，夏天也没有黑头罩

  • 头和胸白色，身体浅灰
  • 嘴暗红，头和嘴呈细长渐尖
  • 初级飞羽尖端黑色
  • 腿暗红色，脖子显得长

第一年幼鸟尾端有黑色横带，翅上有深色区域

在水面上几米高处飞行，见到猎物就扎水；也会在空中捉虫
