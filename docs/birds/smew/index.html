图鉴笔记

雄鸟黑白分明像碎冰，也像熊猫。

  • 雄鸟雪白，飞行时黑白分明
  • 雌鸟身灰，前额头顶栗色
  • 雌鸟颏和脸颊白，眼先黑
  • 嘴尖带钩，边缘有锯齿

雌鸟和未成年雄鸟灰色，额与头顶栗色；雄鸟夏末秋季换蚀羽，像雌鸟但翅上白更多。

起飞很笨拙，要在水面急速拍翅、助跑一阵才飞得起来。
