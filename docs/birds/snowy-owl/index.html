图鉴笔记

雪白的大猫头鹰，白天也活动，头圆没有耳羽簇

  • 几乎纯白，带黑色扇形斑点
  • 头部浑圆雪白，没有耳羽簇
  • 眼睛黄色，嘴黑色
  • 趾上羽毛浓密、白色，爪黑色

雄鸟体型明显小于雌鸟，也更白；雌鸟和幼鸟黑斑更多

它的羽毛浓密，气温−50℃时也能保持38到40℃的体温。
