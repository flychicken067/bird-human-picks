图鉴笔记

深色的中大型鹱，翅僵直，左右倾斜着贴水面滑翔。

  • 羽色深，弱光近黑，强光巧克力褐
  • 翼下中央有一道银色条纹
  • 飞行时翅膀僵直，很少拍翅
  • 翼尖几乎擦到水面

标记实验显示，新西兰繁殖的个体一年行程可达约7.4万公里。
