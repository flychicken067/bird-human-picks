图鉴笔记

嘴像小汤匙的小型涉禽，是极危物种。

  • 嘴呈汤匙形
  • 夏羽头颈胸红棕，有暗褐纵纹
  • 冬羽没有红色，上身淡褐灰
  • 下体全白，脚黑色

觅食时把嘴探进泥里，低头往前走，嘴左右扫动。
