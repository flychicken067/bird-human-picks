图鉴笔记

中国台湾特有的蓝紫色大型雉，雄鸟白冠白尾，脚是红的。

  • 雄鸟胸腹腰有蓝紫色金属光泽
  • 白色冠羽，后颈白
  • 红色肉垂
  • 尾羽白色，脚红色

雄鸟胸腹腰蓝紫发亮；雌鸟褐色带黄色箭形斑和复杂横纹，外侧尾羽栗红。
