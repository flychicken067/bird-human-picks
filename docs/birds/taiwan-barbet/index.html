图鉴笔记

绿身子，头上蓝黄红黑四色，叫声像敲木鱼。

  • 身体翠绿，头有蓝黄红黑四色
  • 眼先有红斑，额与喉黄色
  • 黑色粗喙，嘴基有刚毛
  • 胸上方蓝绿带，下方红带

雌雄相似，雌鸟后颈红斑较小；幼鸟颜色较浅而不鲜明。

中国台湾话叫它「花仔和尚」，形容像和尚敲木鱼般的叫声。
