图鉴笔记

高山箭竹林里的褐头小鸟，翅膀有橙黄色羽毛，不怕人。

  • 头顶到背是褐色，眼圈白色
  • 喉胸灰白，褐纵纹比相似种明显
  • 翅和尾带橙黄色
  • 虹膜淡金褐，喙黑褐

两性没有明显差异；幼鸟比成鸟淡，喙颜色较粉。

受全球变暖影响，它的分布海拔在1992到2014年间有所上升。
