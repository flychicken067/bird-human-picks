图鉴笔记

喙长而向上翘的灰色小型鹬，脚黄色。

  • 喙长而上翘，基部黄，其余黑
  • 背、脸和胸灰色
  • 白色眉纹，或明显或不明显
  • 腹部白色，脚黄色

觅食很活跃，追逐昆虫，有时跑到水边把猎物洗一洗。
