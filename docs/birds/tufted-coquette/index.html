图鉴笔记

雄鸟顶着红褐小冠，颈侧还伸出带黑点的饰羽。

  • 雄鸟头顶有红褐羽冠
  • 雄鸟颈侧饰羽红褐带黑点
  • 雄鸟腰部有一道近白色羽带
  • 喙短直，红色带黑尖

雌鸟没有羽冠和颈侧饰羽，腹面红褐，腹部颜色较浅。

它们在花间平稳飞行时，常让人联想到一只大蜜蜂。
