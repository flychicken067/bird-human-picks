图鉴笔记

比大天鹅小一号，嘴黑，基部黄色区域也更小。

  • 通体白色，脚黑色
  • 嘴黑，基部黄色区域小
  • 上嘴侧的黄色不成前尖
  • 比大天鹅颈短、头更圆

雌鸟比雄鸟稍小，外观没有别的差异；亚成鸟头颈带灰色，嘴基有大片脏粉色。

觅食时常身体浮在水面，用长脖子深入水中取食，民间说「天鹅一脖子扎到底」。
