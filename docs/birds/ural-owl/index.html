图鉴笔记

圆圆的脸，身后拖着一条楔形长尾。

  • 尾长，尾端呈楔形
  • 头圆，面盘也圆
  • 下体深褐纵纹，无横斑
  • 眼睛深褐，较小且靠拢

雌雄外形相似，雌鸟平均略大。

雏鸟约四周就离巢，要到六周左右才会飞。
