图鉴笔记

灰背白腹的中型鹬，涉水觅食时急促点头

  • 上体、脸颈灰色，腹部白色
  • 腿短而深黄
  • 嘴深灰色
  • 繁殖羽腹部有明显横斑

属名Tringa来自亚里士多德提过的一种白臀、会点头的涉禽
