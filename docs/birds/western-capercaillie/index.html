图鉴笔记

体型最大的松鸡，雄鸟深灰褐，胸带金属绿，眼上一块红。

  • 雄鸟体羽深灰到深褐，胸部深金属绿
  • 每只眼上方有一块鲜红裸皮
  • 翼弯有白斑
  • 脚上有羽毛

雄鸟远比雌鸟大；雌鸟上体褐色带黑银横纹，下体浅黄褐。

在斯堪的纳维亚和苏格兰，繁殖季的雄鸟有时会挑战、追赶闯入领地的人。
