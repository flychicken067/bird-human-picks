图鉴笔记

小柳莺，一道长黄眉线、两道翼带，几乎不停地动。

  • 长长的黄色眉线
  • 翅上两道黄白色翼带
  • 三级飞羽羽缘黄色
  • 上体绿色，下体白色

每年秋天英国通常能发现数百只，它们从乌拉尔迁来，飞了3000到3500公里。
