怎么选的

这里说明每张照片是怎么选出来的，能说明什么，不能说明什么。

目前收录 1,209 种。全量查询仍在进行，入选数还会增加。

选图步骤

  1. 鸟种名录跟随 AviList 2026，只收物种划分没有调整过的鸟种。
  2. iNaturalist 的野外研究级观测，至少 3 个账号当前认定为这个物种，认定跨至少 3 个不同月份，没有人给出别的物种。
  3. 只用 CC0、CC BY 或 CC BY-SA 授权的照片，原图长边至少 1200 像素。
  4. 检测模型只看画面里有几只鸟、鸟多大、有没有人手，不判断物种。
  5. 逐张看图，排除被遮挡、只拍到局部、死鸟、家禽、手绘画和拍错的照片，共排除 367 张，每张都记录了原因。
  6. 每张图都有报错入口，被人指出的错误会公开修正。

常见问题

为什么用照片，不用 AI 画？

我们想让物种对不对由人来判断。照片是人拍的，物种由多人鉴定，每一步都能追溯到具体的人。代价是风格不统一，数量也比全部画出来少。

准吗？

比单人鉴定更可靠，但 3 个账号不等于 3 位专家，他们也可能跟随别人的鉴定。没有鸟类学家逐张核对过，辨识细节请以正式图鉴为准。

发现错误怎么办？

每种鸟的页面都有报错链接，已经填好鸟名。请写明哪里不对、你怎么知道的，我们会换图并在更新记录里写明。

我是摄影师，不想被收录。

在 GitHub 提 issue，写上鸟名或照片链接。我们会在 7 天内换掉这张照片，以后也不再使用。

怎么引用？

按照片自身的授权署名摄影师，并注明来自 iNaturalist。每种鸟的页面都有现成的引用文字。CC BY-SA 的照片修改后要按同样的授权分享。

和花叔的贴纸是什么关系？

花叔的 huashu-bird-sticker 给每种鸟画了一张 AI 贴纸。我们想看看只用人的判断能做到什么程度，所以每种鸟都可以和他的贴纸对比。两版谁错得少，要等公开后比较各自被人指出的错误。

数据来源

  • 照片和鉴定：iNaturalist 用户，照片按各自的授权使用。
  • 分类、体型、保护等级：huashu-bird-sticker 整理的数据（MIT），其中体型来自 AVONET 和图鉴，保护等级来自 AviList（BirdLife）。
  • 各语言鸟名：AviList（CC BY 4.0）和 IOC 世界鸟类名录（CC BY 3.0）；分布：AviList 2026 和 IOC 15.2。
  • 中文图鉴笔记：huashu-bird-sticker（CC BY-SA 4.0）。
