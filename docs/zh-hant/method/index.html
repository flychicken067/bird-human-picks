怎麼選的

這裡說明每張照片怎麼選出來，能說明什麼，不能說明什麼。

目前收錄 1,209 種。全量查詢仍在進行，入選數還會增加。

選圖步驟

  1. 鳥種名錄依照 AviList 2026，只收物種劃分沒有調整過的鳥種。
  2. iNaturalist 的野外研究級觀察，至少 3 個帳號目前認定為這個物種，認定跨至少 3 個不同月份，沒有人給出別的物種。
  3. 只用 CC0、CC BY 或 CC BY-SA 授權的照片，原圖長邊至少 1200 像素。
  4. 偵測模型只看畫面裡有幾隻鳥、鳥多大、有沒有人手，不判斷物種。
  5. 逐張看圖，排除被遮擋、只拍到局部、死鳥、家禽、手繪畫和拍錯的照片，共排除 367 張，每張都記錄了原因。
  6. 每張圖都有回報入口，被指出的錯誤會公開修正。

常見問題

為什麼用照片，不用 AI 畫？

我們想讓物種對不對由人來判斷。照片是人拍的，物種由多人鑑定，每一步都能追溯到具體的人。代價是風格不統一，數量也比全部畫出來少。

準嗎？

比單人鑑定更可靠，但 3 個帳號不等於 3 位專家，他們也可能跟隨別人的鑑定。沒有鳥類學家逐張核對，辨識細節請以正式圖鑑為準。

發現錯誤怎麼辦？

每種鳥的頁面都有回報連結，已填好鳥名。請寫明哪裡不對、你怎麼知道的，我們會換圖並在更新記錄裡寫明。

我是攝影師，不想被收錄。

在 GitHub 提 issue，寫上鳥名或照片連結。我們會在 7 天內換掉這張照片，以後也不再使用。

怎麼引用？

依照片本身的授權署名攝影師，並註明來自 iNaturalist。每種鳥的頁面都有現成的引用文字。CC BY-SA 的照片修改後要以相同授權分享。

和花叔的貼紙是什麼關係？

花叔的 huashu-bird-sticker 為每種鳥畫了一張 AI 貼紙。我們想看看只用人的判斷能做到什麼程度，所以每種鳥都能和他的貼紙對比。兩版誰錯得少，要等公開後比較各自被指出的錯誤。

資料來源

  • 照片和鑑定：iNaturalist 使用者，照片依各自授權使用。
  • 分類、體型、保育等級：huashu-bird-sticker 整理的資料（MIT），體型來自 AVONET 和圖鑑，保育等級來自 AviList（BirdLife）。
  • 各語言鳥名：AviList（CC BY 4.0）和 IOC 世界鳥類名錄（CC BY 3.0）；分布：AviList 2026 和 IOC 15.2。
