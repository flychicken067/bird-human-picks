鸟类人选精选

这一版只收录满足以下条件的鸟种：iNaturalist 上的野外照片，至少 3 个账号在至少 3 个不同月份认定为同一物种，而且没有人给出其他物种的鉴定。每种鸟都和花叔 2.2.0 的 AI 贴纸并排展示。图片全部由人拍摄，物种对错依据人的鉴定，不由模型判断。

规则和局限
  • 鸟种必须在花叔版有贴纸，且 AviList 没有调整过它的物种划分，iNaturalist 的学名也必须完全一致。
  • 照片需在 2025-11-05 之前上传，授权为 CC0、CC BY 或 CC BY-SA，原图长边至少 1200 像素。
  • 每张照片先由鸟类检测模型筛选构图：画面里只能有一只鸟、鸟要够大、不能有人或手。之后由 Claude 逐张看过，排除被遮挡、只拍到头、死鸟、家禽、手绘画、翻拍屏幕和拍错鸟的照片，每条排除记录都在 eye-check.csv。模型和 Claude 都不判断物种。
  • 3 个账号不等于 3 位专家，他们也可能跟随别人的鉴定。这一版还没有经过鸟友评审。
  • 真实照片的姿态、光线和背景各不相同，不是统一的透明贴纸风格。
  • 图片直接从 iNaturalist 和 GitHub 加载，需要联网才能显示。
